# agents-md

A language-agnostic `AGENTS.md` — instructions for AI coding agents,
covering scope discipline, design judgment, naming, code structure,
defensive programming, comments, testing, commit hygiene, and user-facing
impact.

## Usage

Copy `AGENTS.md` into the root of a repository. It's a default, not a
mandate — the file itself says to defer to a repo's existing conventions
where they conflict, and to a linter/formatter for anything syntactic.
